# Sources and maintenance

Interface references reviewed on 2026-10-23. Review links and supported versions each quarter and whenever changing an integration. External product terms and model availability can change.

- [Ollama generation API](https://docs.ollama.com/api/generate): POST /api/generate, non-streaming responses and generation options.
- [Ollama embeddings API](https://docs.ollama.com/api/embed): POST /api/embed and input arrays.
- [Qwen2.5 1.5B model](https://ollama.com/library/qwen2.5:1.5b): default small local model and model license.
- [Nomic embedding model](https://ollama.com/library/nomic-embed-text): local retrieval model.
- [Chroma documentation](https://docs.trychroma.com/): collection add/query operations.
- [LangGraph Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api): state graphs, nodes, edges, compile and invoke.
- [FastAPI tutorial](https://fastapi.tiangolo.com/tutorial/): request schemas and local application structure.
- [Streamlit documentation](https://docs.streamlit.io/): local dashboard execution.
- [n8n license](https://github.com/n8n-io/n8n/blob/master/LICENSE.md): source-available usage conditions.
- [Docker Desktop license terms](https://docs.docker.com/subscription/desktop-license/): eligibility-dependent subscription requirements.
- [OWASP LLM project](https://owasp.org/www-project-top-10-for-large-language-model-applications/): AI application risk guidance.
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework): governance and risk-management reference.

Use sources to verify interfaces, not to claim certification. Before releasing a workshop, run live labs on the target OS, record dependency versions and model identifiers, and update [validation status](11-validation-status.md). No cloud quota or paid-product capability is assumed.
