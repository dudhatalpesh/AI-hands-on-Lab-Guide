# Glossary

| Term | Meaning for an advisor |
| --- | --- |
| AI / ML / deep learning | Broad intelligent-system field / learning from data / layered neural-network methods |
| Generative AI | Models that synthesize content rather than only classify or predict a scalar |
| LLM | Language model trained to predict/generate token sequences |
| Token | Model-specific unit of input/output; not necessarily a word |
| Parameter | Learned model weight; count alone does not predict task quality |
| Context window | Bounded input and output capacity available during inference |
| Temperature | Sampling control; not a truthfulness control |
| Embedding | Numeric representation used to compare semantic features |
| Vector database | Index/store for vector retrieval; authorization must be designed separately |
| RAG | Retrieve evidence and include it in the generation context |
| Chunking | Splitting documents into retrievable units with provenance |
| Reranking | Rescoring retrieval candidates before selecting context |
| Context engineering | Selecting and organizing instructions, evidence, history and tool results |
| Fine-tuning | Updating model weights on additional training data |
| Hallucination | Plausible but unsupported or incorrect generated content |
| Agent | System that selects actions/tools using model output and observations |
| Orchestration | Explicit control of state, transitions, dependencies and termination |
| Guardrail | A preventive/detective control with a defined scope and measurable limitations |
| Prompt injection | Untrusted text attempts to redirect model or system behavior |
| Groundedness | Whether claims are supported by the supplied evidence |
| Recall@k | Fraction of relevant items retrieved among the top k results |
| Human in the loop | A defined human review/approval point with authority and accountability |
| TCO | Infrastructure, integration, review, operations and lifecycle cost |
| Model card | Documentation of intended use, training/evaluation context and limitations |
| Data lineage | Traceability of source, transformations, access and lifecycle |
